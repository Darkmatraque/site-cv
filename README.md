# Site CV — Kevin Baumann

Site personnel de recherche d'emploi, pensé pour être simple, rapide, un peu fun et facile à héberger sur GitHub Pages.

## Contenu

- Profil et recherche d'emploi à Neuchâtel et alentours
- Expérience en terminaison horlogère et mécanique automobile
- Compétences et qualités
- CV PDF consultable/téléchargeable
- Mode recruteur pressé
- Console interactive
- Plusieurs easter eggs et micro-animations
- Responsive mobile / desktop
- Aucun framework ni dépendance externe

## Mise en ligne avec GitHub Pages

Dans GitHub : **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.

## Fichiers

- `index.html` : structure et contenu
- `styles.css` : design et responsive
- `script.js` : animations, terminal, easter eggs
- `assets/CV-Kevin-Baumann.pdf` : CV public

> Attention : le CV PDF contient des données personnelles. Comme le dépôt et GitHub Pages sont publics, le PDF sera lui aussi public.
